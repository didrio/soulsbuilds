# Decisions

Why the stack is what it is, so nobody re-litigates it by accident. Change a row only with the owner, and date
it. "Owner's call" = decided by the owner.

| Area             | Decision                                                                                                                                     | Why / when                                                                                                                     |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Goal             | Finish and **relaunch publicly** on the existing Firebase project                                                                            | Owner's call, 2026-11-14                                                                                                       |
| Backend          | **Firebase** (Auth, Firestore, Hosting); no Cloud Functions                                                                                  | Project and domain already exist (2026-11-14). Functions need the paid Blaze plan; use rules + transactions                    |
| Build tool       | **Vite** (replaced Create React App)                                                                                                         | CRA is deprecated (2026-11-14, T1)                                                                                             |
| Framework        | React 19 SPA, react-router 7 in library mode                                                                                                 | Minimal change from 2022; SSR only if per-build share previews become a priority (backlog)                                     |
| Styling          | **Keep styled-components** (v6) + theme tokens, no raw hex in components                                                                     | Owner's call, 2026-11-14: lowest churn for ~145 styled blocks; it's in maintenance mode but works with React 19                |
| Client state     | **Redux Toolkit** for the build being edited                                                                                                 | Owner's call, 2026-11-14: the editor's nested slot state fits RTK; already written                                             |
| Server state     | **TanStack Query** for Firestore data (T4)                                                                                                   | Owner's call, 2026-11-14: caching, loading/error states; never copy server data into Redux                                     |
| Language         | TypeScript strict, feature folders, `@/` alias (T2)                                                                                          | Types make the T3/T4 refactors safe for agents                                                                                 |
| React Compiler   | On, via `@rolldown/plugin-babel` + `reactCompilerPreset()` (T2)                                                                              | Built cleanly on the whole app (2026-11-14); auto-memoization instead of hand-written `useMemo`/`useCallback`                  |
| Lint / format    | ESLint 9 flat (typescript-eslint, react, react-hooks, jsx-a11y) + Prettier (shared config with mobile/base)                                  | ESLint 10 / TS 7 not supported by plugins yet (2026-11-14)                                                                     |
| Tests            | Vitest + Testing Library; Playwright (`playwright-core` + installed Chrome) for screenshots/e2e; `@firebase/rules-unit-testing` (T3)         | Same patterns as loz; no browser downloads                                                                                     |
| Local data       | Firebase emulators under `demo-soulsbuilds`, seeded on start                                                                                 | Local work can never touch production (2026-11-14)                                                                             |
| Leaked key       | Deleted from the tree going forward; **no history rewrite**; key revoked in GCP                                                              | Owner's call, 2026-11-14: once revoked, the copy in history is useless                                                         |
| Game data source | 2022 rankedboost scrape, frozen; **T7 chooses the new source with the owner**                                                                | Licensing (2026-11-14)                                                                                                         |
| Agent workflow   | AGENTS.md + CLAUDE.md, TICKETS.md (one ticket per session), `/start` `/wrap` `/ticket` skills, Prettier hook                                 | Same loop as mobile/base and loz (2026-11-14)                                                                                  |

| E2E              | `@playwright/test` driving the installed Chrome (`executablePath`), on the emulators; `npm run e2e`                                          | 2026-11-14 (T4): no browser downloads; CI uses the runner's Chrome                                                             |
